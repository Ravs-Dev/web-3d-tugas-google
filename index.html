09 / GET STARTEDLESS CODE / MORE MOTION

Make it move.
Make it yours.

RAVS Motion pairs Anime.js for expressive interface animation with Three.js for the central Google G model, exported from Blender as GLB.

Explore Anime.js documentation ↗
motion.js
import { animate, stagger } from 'animejs';

// Animate a collection with a little rhythm.
animate('.element', {
  y: [32, 0],
  opacity: [0, 1],
  delay: stagger(80),
  ease: 'outExpo',
  duration: 900,
});
